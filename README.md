# YouTube - De-emphasize Watched Videos

YouTubeで視聴済み、または視聴途中の動画を暗く表示するUserCSSです。  
ホーム、検索結果、動画視聴ページ右側のおすすめ欄に対応しています。

## Features

- 視聴済み動画を暗く表示
- 動画視聴ページ右側のおすすめ動画にも対応
- ホバー時は通常表示に戻す
- Stylus向け

## Usage

1. Stylusをインストール
2. `youtube-deemphasize-watched.user.css` の内容を新しいスタイルに貼り付け
3. 対象URLを `youtube.com` に設定
4. 保存

## Notes

YouTubeのHTML構造変更により、将来的に動作しなくなる可能性があります。
